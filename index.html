How to connect a real Garmin watch in the future

Real automatic account-based Garmin Connect synchronization requires a Garmin Developer Program integration and each astronaut's approval. PulseDeck currently supports synthetic readings and import of normalized JSON records. The Personal API is not intended for multi-user services.

Import JSON format: an array of records, for example [{"date":"2026-11-14","sleep_hours":7.5,"resting_hr":62,"steps":8500,"stress_score":27}]. Imported values are not automatically verified as Garmin data. Existing hand-entered daily check-ins are never overwritten.

How to take and record these measurements
Heart rate & blood pressure

Use the approved monitoring device and record readings after resting, following the mission measurement routine.

Body temperature

Use an onboard thermometer. Check unexpected readings again and note any symptoms.

Blood glucose

Use an approved testing device, record mg/dL, and select whether the reading was before or after eating.

Body mass in microgravity

SLAMMD measures mass using a known force and resulting acceleration. Enter the device result in kg.

Record today's measurements

On the ISS, body mass can be measured with SLAMMD, an instrument based on force and acceleration. Enter the instrument value, not a conventional scale weight. NASA reference ↗

DATA SOURCES

Measurements, estimates & research

PulseDeck organizes crew-entered readings and mission logs. It is a NASA Space Apps project and is not a certified medical device. The included astronaut accounts and starting records are fictional.

Wearable health

The wearable section contains synthetic Garmin-style records, and optionally imported local JSON records. No Garmin watch, account or live Garmin API is connected. Garmin integration requires official developer access and account consent.

Measured vs estimated

Daily vitals, glucose, temperature, body mass and dosimeter values are entered or imported. Bone trend and what-if comparisons are reference models, not physical measurements.

Health guidance

Offline responses use rules, while connected AI can discuss records. Neither mode diagnoses disease, approves medication or sends emergency alerts. Follow mission medical procedures for urgent conditions.

ISS food catalog

Foods are documented by space agencies, not a live stock list. Log actual servings. PulseDeck doesn't guess calories or nutrients.

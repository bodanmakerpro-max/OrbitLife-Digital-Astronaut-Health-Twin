# PulseDeck 20.1: поврзување на OLED, RFID и енкодер со ESP32

**Плочка:** класичен ESP32 DevKit / ESP32-WROOM-32, не ESP32-S3.
**Комуникација:** само USB Serial, 115200 baud. Нема Wi-Fi, ниту LCD со 16 пинови.

| OLED SSD1306 (I2C) | ESP32 |
|---|---|
| GND | GND |
| VCC | 3V3 |
| SCL | GPIO 17 |
| SDA | GPIO 16 |

| RFID RC522 (SPI) | ESP32 |
|---|---|
| SDA / SS | GPIO 21 |
| SCK | GPIO 18 |
| MOSI | GPIO 23 |
| MISO | GPIO 19 |
| RST | GPIO 22 |
| VCC / 3.3V | 3V3 |
| GND | GND |

| Енкодер KY-040 | ESP32 |
|---|---|
| CLK | GPIO 32 |
| DT | GPIO 33 |
| SW | GPIO 25 |
| + | 3V3 |
| GND | GND |

**Важно:** сите модули користат заедничка маса. Не доведувајте 5 V до RC522 или до GPIO пиновите на ESP32.

## Софтвер

1. Во Arduino IDE инсталирајте `U8g2` и `MFRC522`.
2. Отворете `ESP32_OrbitLife_OLED_Mission/ESP32_OrbitLife_OLED_Mission.ino`.
3. Изберете ESP32 Dev Module и соодветниот COM приклучок, па направете Upload.
4. Затворете го Arduino Serial Monitor, кој би го зафатил COM приклучокот.
5. Стартувајте `py -3.13 server.py` и на дното од Welcome Page изберете `USB / ESP32 Connection` и COM приклучок, па притиснете Connect.
6. За автоматска RFID најава, првпат спарете ја картичката со профилот преку администрацијата. Види `RFID_AND_ESP32_SETUP_MK.md`.

## Управување

- Без RFID: OLED прикажува PulseDeck и три опции за јавен преглед, исхрана и најава.
- Спарена RFID: го најавува соодветниот астронаут во локалната веб-апликација и го отвора личниот преглед.
- Вртење: секој физички чекор десно поместува точно една ставка надолу; секој чекор лево поместува една ставка нагоре. Истото движење оди и на веб-екранот.
- Краток притисок: ја отвора избраната функција.
- По отворање страница: вртењето и притисокот управуваат со видливи контроли во прелистувачот.
- Долго притискање: враќање на почетното мени.
- Сите функции може да се користат и со допир.

Картичката **не ја открива лозинката**: за образовна демонстрација дозволува брзо локално најавување по спарување. За реални медицински записи, UID-базирана RFID картичка не е доволна за безбеден пристап.

## Ако енкодерот врти наопаку или не реагира

- CLK = GPIO32, DT = GPIO33, SW = GPIO25, + = 3V3, GND = GND.
- Провери дали имаш нов firmware на ESP32, не е доволно само `git pull` за да се смени кодот на плочката.
- Во `.ino` можеш да ја смениш `ENC_DIRECTION=1` на `ENC_DIRECTION=-1` ако десно оди нагоре наместо надолу.
- Firmware чита по еден CLK импулс за секој KY-040 чекор и филтрира механичко тресење 5 ms. Некои модели енкодери имаат поинаков број импулси по чекор и може да требаат дополнителни прилагодувања.
- За тест без веб апликација отвори Arduino Serial Monitor на **115200 baud**. При едно вртење треба да видиш еден JSON ред `{"type":"rotate","delta":1}` за десно и `-1` за лево. Затвори го Serial Monitor пред поврзување со PulseDeck.

### Статус на проверката

Серверскиот протокол и прелистувачкиот почетен екран се проверени со симулирани настани. Вистинската OLED и ESP32 комбинација треба да се тестира на хардвер.

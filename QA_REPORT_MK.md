# OrbitLife 19.1: проверка на демонстрациското издание

- Проверка на Python и JavaScript синтакса.
- 88 интеграциски проверки на серверот со нова привремена база.
- Осум сметки се достапни, старите `astro09` и `astro10` не се достапни.
- Јавното мени враќа точно осум активни профили.
- Приватните здравствени записи бараат најава; до туѓите записи нема пристап.
- Итни пријави се зачувуваат и се прикажуваат како јавни известувања без откривање на медицинскиот опис.
- Испробани се контролите на серверот за OLED во отсуство на хардвер.
- Миграцијата на постара база ги задржува историските записи за AST-009 и AST-010, но ги деактивира профилите.
- Додадена е симулација на USB RFID настан со автоматска најава, проверка на картичка по астронаут, истекување и еднократна употреба.
- Мени за USB поврзување без лозинка, со зачувување и исклучување, е проверено преку серверските API тестови.
- JavaScript синтаксата е проверена. Автоматизирано отворање на страницата во Chromium беше блокирано од околината, па новиот визуелен интерфејс не е потврден во прелистувач.

**Не е потврдено:** компајлирање на Arduino проектот во физичката околина на корисникот, реално RFID читање и двонасочна USB Serial синхронизација на уредот, клиничко тестирање, интеграција со вистинска опрема.

Демонстрацискиот систем не е одобрен за клинички или летачки медицински одлуки.

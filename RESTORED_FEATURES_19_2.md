# PulseDeck 19.2 restored interface

The general Quick AI chat bubble is available in the bottom left on the Welcome screen and the rest of the portal, regardless of login state. It answers only general questions. Offline mode requires no API key. Connected mode needs local API configuration and may be unavailable to guests.

The Welcome Page now has an All PulseDeck mission tools dropdown; the crew dashboard also has an Explore all mission tools dropdown. Most medical tools still require login or a paired RFID card; general Quick AI is public. Signed-in quick action links are also visible again. The original modules and API routes have not been removed.

RFID card pairing, automatic sign-in, serial port connection and Back to Welcome remain from 19.1.
